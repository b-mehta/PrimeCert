# The KiB a case may reach before run.sh kills it, replacing the default 14000000.
#
# 15200000 here because the 10^9 base sieve peaks 14272748 KiB at batch length 4, which is over
# the default by 1.9% and under this by 6%. The default is low enough to kill a case before the
# runner itself dies, which is what keeps the job log readable, so raising it trades that safety
# for an answer and should go back to the default once the answer is in.
